# Saldo

Demo mobile per una futura app personale di bilancio.

## Cosa include

- riepilogo saldo mensile
- entrate, uscite e importi da incassare
- categorie spesa
- ultimi movimenti demo
- obiettivo fondo sicurezza
- popup demo per aggiungere un movimento
- base PWA con manifest, icone e service worker

## Nota dati

In questa versione i dati sono finti e non vengono salvati.
Il prossimo passaggio puo essere `localStorage` con export/import backup, oppure database online se serve sincronizzazione tra dispositivi.
